## 三、哪些结论可以直接用，哪些还得等

### ✅ 可直接引用（有日志或代码证据）

| 结论 | 证据 |
|---|---|
| KV 池 5,696 token | 启动日志 `GPU KV cache size: 5,696 tokens` |
| 单请求 4,096 token 时并发上限 1.39x | 同一条日志 |
| 并发卡在 2 不是序列数上限导致 | `sched/scheduler.py:108` + 实测 `--max-num-seqs 8` |
| 355 ÷ 136 = 2 路并发 | 纯算术，块数来自日志 |
| vLLM 与 SGLang 单流基本持平 | 71.1 vs 73.6 tok/s（同负载同并发） |
| 前缀缓存长 prompt 6.01× | 单变量 A/B，TTFT 8.089→0.104 s |

### ⚠️ 需要重跑才能当定论

| 结论 | 为什么 |
|---|---|
| transformers 慢 5.7–7.3× | 已修 chat template 口径，但已有数据是旧口径测的 |
| C 组 chunk 切小后并发是否上升 | 实验设计好了，**还没跑** |
| `--gpu-memory-utilization 0.88` 时 KV 是否 ≈ 7,440 token | 预测未验证 |
